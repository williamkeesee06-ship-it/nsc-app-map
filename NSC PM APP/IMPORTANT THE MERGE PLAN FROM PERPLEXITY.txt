Three-Level Architecture (LOCKED — from MAP_WORKSPACE_LAYERS_SPEC.md)
Map View (existing home) — Quick Reference Layer renders the "gist", NOT granular as-built data. DO NOT touch the home page beyond adding the "Enter Workspace" navigation.

Workspace (/asbuilt?jobId=...) — focused single-job editor. On mount: load job from Smartsheet, auto-center + zoom to job lat/lng, hide other pins, mount canvas + tool palette + layers panel.

Layers Panel (right side) — top: job totals · middle: layer list by foreman+date · bottom: grouped objects per layer.

Layer Model
One as-built layer per foreman per date.

Previous layers visible by default but locked — require explicit unlock toggle to edit.

New objects → active daily layer.

Feature shape: { toolType, label, status, size?, coords, layerId, jobId, createdBy, workDate, billingEntries }.

Engineering Print Overlay
PDF/image upload per job, manual alignment (control points / rotate / stretch).

Visual reference only — never source of truth for billing.

ONE active "Engineering Print" badge per job, reassignable to revised prints. Older prints stay attached unless deleted.

Attachment system: PDFs + normal files, BLOCKS KMZ/GeoJSON, syncs to Smartsheet attachments column.

Quick Reference Layer
Auto-generate on first as-built save for a job (gist extraction).

Map View always renders the saved gist, NOT live as-built.

Job-card sync icon: none / out-of-date (red) / synced (green) — manual re-sync only.

Quick Mode prompt sequence: Status (NEW/REMOVED) → Aerial or Underground → Cable family (Fiber/Copper/ASW/BSW) → optional label. Visual rules: aerial solid, UG dashed, NEW red, REMOVED green — same visual language as As-Built Mode.

Contract Rules — PRESERVE VERBATIM (do not "improve")
Status colors hardcoded: NEW #FF0000, EXISTING #000000 (label-only, no billing), REMOVE #00AA00, XFER #0000FF, DERELASH #A020F0, civil (TRENCH/BORE/POTHOLE) #8B4513.

No COAX anywhere (not a Lumen contract item).

Only 10M strand (6M is removed).

A-Tag auto-prefix: poles auto-prefix A- if not present.

Occupied conduit adder: bills at same footage as associated cable tool.

Splice pits: always NEW-only.

MH crew/dewatering checkboxes default UNCHECKED.

SELECT BACKFILL 0.5 CY — preserve decimals, NO Math.round.

Hand Set default unchecked.

Ground Rod only renders when Status=NEW on pole.

MH/HH/PED size NOT rendered on canvas unless Status=NEW.

Removal lines: green with intermittent X marks along the line.

XFERS routing: setTool("XFERS") BEFORE activeCategory gate (explicit bug fix — keep this order).

Label Rules
Pole labels required, auto-format to A-##### if user omits prefix.

MH/HH/PED labels optional.

Line labels optional; if entered, exact text becomes the rendered callout for that line.

Production-Readiness Priorities (user-locked order)

Canvas stability — draw, select, move, delete, undo/redo, zoom, pan, background image behavior.

Billing integrity — every tool writes correct units into state.unitMap, removes stale entries on delete, preserves decimals.

Export + persistence — save/load + PDF export submission-ready every time.
