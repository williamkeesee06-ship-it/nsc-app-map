Phase 7 Scope (4 features, in this order)
1. Layers by Foreman + Date (DO THIS FIRST — foundational)
Data model — every drawn feature persists:

text
{ toolType, label, status, size?, coords, layerId, jobId, createdBy, workDate, billingEntries }
createdBy = foreman (read from Smartsheet column 4146149265985412 for the active job, or user-selected if multiple foremen on the job)

workDate = ISO date of the layer

layerId = stable id, one per (jobId, createdBy, workDate) tuple

Layer rules:

One layer per foreman per date.

New objects always write to the active daily layer.

Previous layers visible by default, read-only (locked).

Per-row "Unlock for editing" toggle moves a layer into edit mode explicitly.

Active-layer banner in the workspace top strip — user always sees where new objects land.

Right panel layer list (middle section):

List layers grouped by createdBy + workDate, newest first.

Per-row controls: show/hide · make active · rename date · explicit unlock.

Bottom section per layer = grouped objects (Cable, Removed Cable, Poles, MH, HH, PED, Notes) with counts/footage beside each group — NOT a flat feature list.

2. Engineering Print Overlay
"Attach Engineering Print" action in the workspace.

Upload PDF or image → manual alignment UI: draggable corner control points + rotate + opacity slider.

Save as toggleable overlay layer (separate from as-built layers).

One active "Engineering Print" badge per job at a time. Reassignable — when user sets a different print as Engineering Print, the badge moves. Older prints stay attached unless deleted.

Visual reference ONLY — never source of truth for billing. Do not derive measurements from it.

Badge surfaced on map-view job card as "Engineering Print Attached" indicator near top of card.

3. Attachment System
Per-job attachment list (PDFs + normal files).

Hard reject KMZ and GeoJSON uploads with a friendly error message.

Sync uploads/deletes to Smartsheet attachments for that row.

"Set as Engineering Print" button on any PDF attachment → wires into #2.

4. Quick Reference Layer (auto-sync gist)
On first as-built save for a job → auto-generate the Quick Reference Layer gist from the as-built data. Gist = simplified cable lines + key points only, no billing data.

Map view renders the saved gist, never live as-built data. No background recompute.

Job-card sync icon states:

None → (auto-creates on first as-built save)

Out-of-date → red mark (set whenever the as-built layer set changes after last sync)

Synced → green checkmark

Manual "Sync Reference Layer" button on the job card recomputes the gist from latest as-built.

Quick Mode entry path on the map view (lightweight backfill for older jobs without full as-built):

Prompt sequence: Status (NEW / REMOVED) → Aerial or Underground → Cable family (Fiber / Copper / ASW / BSW) → optional label

Visual rendering rules (MUST match As-Built Mode):

Aerial cable → solid line

Underground cable → dashed line

NEW → red #FF0000

REMOVED → green #00AA00
